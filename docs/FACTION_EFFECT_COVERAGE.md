# Faction effect coverage

One row per effect of every faction ability, faction technology, agent, commander, hero, faction promissory note, Thunder's Edge breakthrough and the five generic promissory notes, for the 426 effects below (34 faction entries in `crates/ti4-content/content/factions.json`, Keleres counted once with their three heroes and riders separate; unit/flagship/mech abilities are out of scope). New tests are in `crates/ti4-engine/src/faction_effects_tests/` (`f1` base Arborec..Naalu, `f2` base Nekro..Keleres, `f3` Prophecy of Kings, `f4` Thunder's Edge, breakthroughs and generic notes), named `<card id>_<n>_<what>`. Faction technologies are only pointer rows to `docs/TECH_EFFECT_COVERAGE.md`.

Test column: a bare `faction_effects_tests::fN::name` is a new test; `<name>.rs: test` means an existing test in `crates/ti4-engine/src/factions/<name>.rs` (module `tests`); other prefixes (`production.rs:`, `tactical.rs:`, `game.rs:`, `leaders.rs:`, `promissory.rs:`, ...) name that file in `crates/ti4-engine/src/`. Existing tests were cited only where their names/bodies show the effect through the game path; some are unit-level (called out in the Implementation column).

Status: `pass`, `ignored (MISSING)` = test written, `#[ignore = "MISSING: ..."]`, the engine lacks the effect (`cargo test -p ti4-engine --lib faction_effects_tests -- --ignored` lists them), or `not engine-testable`.

Totals: see the depth summary above for the depth classes; `ignored (MISSING/BUG)` rows would be effects the engine lacks; there are none since rules version 17 (the ten found are listed below).

## Depth summary

Depth classes: EFFECT (drives the real flow and asserts the promised outcome), PLUMBING (registration, thresholds, flags, status transitions), HOOK (calls a hook or helper directly), NONE (no test), MISSING/BUG (engine lacks the effect or gets it wrong; test written and `#[ignore]`d; none left since rules version 17). The Depth cell of a row upgraded by the depth work reads `EFFECT (was <class>: reason)`; the tests are `faction_effects_tests::d1`..`d6`.

## MISSING/BUG found by the depth tests

Ranked by how common the faction/card is (base-game factions first). All ten are fixed at rules version 17 (`RULES_FACTION_BUGFIXES`, `docs/RULES_VERSION.md`); below it the engine behaves as before. Their tests are un-ignored and pass at the current version, each with a legacy assertion at version 16.

1. `ps` Political Secret (generic note, every faction): the owner is also barred from playing action cards (component actions and reactions) and from using faction abilities until the agenda resolves (`laws::political_secret_bars`; `d3::ps_1_...`).
2. Status-phase action card hand limit (every faction, not a card row): the status phase draw now goes through `action_cards::enforce_hand_limit` (`status.rs`; `d3::status_phase_draw_enforces_the_action_card_hand_limit_for_a_plain_seat`).
3. `nes` Letnev Non-Euclidean Shielding: the combat window's sustain step cancels two hits (`combat.rs`, `Stage::Sustaining`; `d1::nes_1_...`).
4. `letnevcommander` 2 Rear Admiral Farran: the combat window's sustain step asks `letnev_commander_trade_good` (`d1::letnevcommander_2_...`).
5. `letnevagent` Letnev agent: `borrowed_round_agents::owner_abilities` registers `leader:letnev:letnevagent:COMBAT_ROUND_STARTED:after` (`d1::letnevagent_1_...`).
6. `letnevhero` 2 Darktalon: `fleet::over_supply` honours `fleet::is_unlimited` (`d1::letnevhero_2_...`).
7. `saar_spacedock` Floating Factory I: Construction (and the Construction Rider) place the Floating Factory in the space area of the chosen planet's system (`strategy_cards::construction_placement`; `d1::saar_spacedock_2_...`).
8. `hacan_mech` Pride of Kenara: a transaction can carry the planet card (`transactions::PlanetTerm`, shapes `kp`/`kq`, free-form field `p`); the giver's units move to another planet the giver controls (`d1::hacan_mech_1_...`, `hacan_mech_2_...`).
9. `naalu_mech` Iconoclast (PoK printing): +2 against an opponent with a relic fragment (`factions/naalu.rs:unit_roll_modifier`; `d2::unit_naalu_mech_1_...`).
10. `naalu_mech_omega`: other players cannot use ANTI-FIGHTER BARRAGE while it is in the system (`combat::omega_forbids_barrage`; `d2::unit_naalu_mech_omega_1_...`).

Open design questions, not engine bugs: Keleres Tribuni and the Bastion flagship / Deepwrought mech production values are printed-card questions and were left as they are.

Stale entries: `faction_abilities::blocked()` still names propagation, mitosis, stall_tactics and telepathic, all of which are implemented; the registered-abilities filter hides them, so the list is only misleading text.

## Missing or broken effects

None. The ten found by the depth tests are fixed at version 17 (list above).

Version 16: The four effects that were missing are implemented behind rules version 16 (`RULES_FACTION_EFFECTS`, `docs/RULES_VERSION.md`); below it the engine behaves as before, so old saves replay unchanged:

1. `letnevbt` Gravleash Maneuvers 2: +X to one ship's roll in space combat (`combat.rs:gravleash_maneuvers`). The card lets the Letnev choose the ship; no question is asked, the bonus goes to the die it helps most (ties: first ship in board order).
2. `solagent` Sol agent: the owner has a `GROUND_COMBAT_ROUND_STARTED` window (`borrowed_round_agents.rs:owner_abilities`) and picks the ground force; `roll_ground` also reads the direct `dispatch_leader` mark.
3. `pop` Promise of Protection: waits in hand and is placed with its ACTION (`faction|mentak|pop`).
4. `ralnelcommander` Watchful Ojz: unlocks for the last seat to pass, at the pass.

Also changed at version 16: Rear Admiral Farran's trade good is a real choice (`letnev_commander_trade_good`). The Naaz fragment purge already awarded the Shard of the Throne's point (it goes through `relics::gain`; test `naaz.rs tests::fabrication_drawing_the_shard_of_the_throne_awards_its_point`), so nothing changed there.
