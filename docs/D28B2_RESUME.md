## A position the core cannot hold answers the neutral value (documented, by function)

A table with no faction seated (`fixtures::game`), an id the tables do not know, more than 16 owners, or content that is not the embedded corpus: `None` / 0 / empty / false for `objectives::*progress*`, `secrets::progress`, `scoreable_*`, `held_secret_progress*`, `objectives_implicating_system`, `bombardable`, `space_cannon_guns`, `faction_abilities::has`, `buildable_for`, `native_payment_planets`, `production_cost_reduction`; `fleet::standing` is all zeros; `hand_limit` is the printed 7; `planet_value_boosts` lists the attachment cards only; `effective_move_value_for_ship` is the printed move with the boosts (also without an `index`). Also neutral: a priced objective the core cannot decide (a seat with ocean cards: Deepwrought is not a lobby faction), an id of an imagined set the tables do not know (dropped), Keleres' IIHQ term (as in the core's `Seen`; no Keleres seat can be seated in the lobby), and `neighbour_planet_counts` does not count the planets an `imagining` position adds to the player's own side. `home_planets_not_controlled` reads the core's `Player::home_planets`.

**Redacted views are held** (regression test `a_redacted_view_answers_as_the_legacy_ones_do`, which failed on the first version): the host projects from the state a seat may see, where every other seat's hand is a row of `HIDDEN` markers that the typed state cannot hold as cards. `queries::view::loadable` replaces the markers by placeholder cards (sizes kept) before every load (`SeenOwned::from_parts`, `Loaded::of`, `ProdView::of`, `Full::of`), and the secrets of a masked seat are never read (`scoreable_secret` 0, no held-secret rows).

**Kernel lesson** (found by the mutation numbers, regression test `production_cost_reduction ... particle synthesis`): `ties::core_adapter::kernel_for(sources)` is the movement table only; every read that asks a faction hook (economy, combat, strategy, direct) must use `ties::production_view::kernel_of(sources)` (all modules). `queries::view::Loaded` does.
